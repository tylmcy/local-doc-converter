# Local Document Converter v1.0.0

首个公开稳定版本。本项目是一个完全本地、离线运行的 TXT、Markdown 与 DOCX 批量互转工具，面向个人使用与作品集展示。

## 主要功能

- 支持 TXT、Markdown、DOCX 之间的六条转换路径。
- 支持多文件上传、批量转换、单文件下载和 ZIP 打包。
- 自动识别 UTF-8、GBK、GB18030 等常见中文编码。
- 离线识别中文章节、数字标题、列表、简单表格和代码块。
- 尽可能保留标题、列表、表格、代码块、链接和图片语义。
- 为每个文件生成结构统计、警告和潜在格式损失报告。
- 输出保留原始文件名，同名时自动避让，不覆盖源文件。
- 服务仅绑定本机 `127.0.0.1`，任务完成后自动清理临时文件。

## 验证

- 23 项自动化测试通过。
- 六条真实转换路径通过。
- 五文件批处理、ZIP、图片往返和 Streamlit 页面测试通过。
- 目标环境：MacBook Air M5、Python 3.12、Pandoc 3.11。

## 安装

请参阅仓库 README。首次安装 Python 依赖和 Pandoc 时需要联网，文档转换过程本身可以离线完成。

## 已知限制

- 不承诺复杂 DOCX 精确无损。
- 页眉页脚、批注、修订、文本框、宏、SmartArt、复杂表格和精确分页可能丢失。
- 远程图片不会下载。
- 当前版本不提供安装包，需要 Python、uv 和 Pandoc。

完整变更见 `CHANGELOG.md`。
