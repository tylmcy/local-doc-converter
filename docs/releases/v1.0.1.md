# Local Document Converter v1.0.1

这是 v1 系列的安全加固版本，不新增转换格式，也不改变原有六条转换路径。

## 安全改进

- DOCX 输入在进入 Pandoc 前执行只读、流式 ZIP 容器预检。
- 拒绝路径穿越、绝对路径、反斜杠路径、符号链接、加密条目和重复条目。
- 限制 ZIP 条目数量、单条目解压体积、总解压体积和压缩比，降低异常压缩文件造成的资源耗尽风险。
- 完整流式读取触发 CRC 校验，损坏容器会生成可理解的失败报告。
- 宏、OLE 嵌入对象和外部关系不会执行或主动访问，只写入转换警告。
- 单个异常 DOCX 不会阻断同一批次中的其他文件。

## 验证

- 38 项自动化测试通过。
- 六条真实转换路径通过。
- 示例 DOCX 预检与 DOCX → Markdown 实际转换通过。
- Python 编译、锁文件和差异格式检查通过。

## 兼容性

- 支持范围仍为 TXT、Markdown、DOCX。
- 目标环境仍为 MacBook Air M5、Python 3.12、Pandoc 3.11。
- 不升级 pytest，不新增运行时依赖。
- 本版本不提供安装包。

该预检用于降低异常 DOCX 容器风险，不等同于病毒或恶意代码扫描。
