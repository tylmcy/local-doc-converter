# Local Document Converter v2.0.0 发布说明

发布日期：2026-09-24。本版本正式加入 PDF → TXT，同时保持 V1 六条转换路径兼容。

## 本版范围

- 新增 PDF → TXT：文本页原生提取，扫描页和异常文字层页使用预先准备的本地 PaddleOCR PP-OCRv5；PDF 不支持输出 Markdown 或 DOCX。
- 保留 TXT、Markdown、DOCX 六条现有路径；文本型 PDF 不依赖 Pandoc，扫描 PDF 需要本地 OCR 环境与模型。
- 对 PDF 进行文件头、结构、加密、页数、对象数、页面尺寸和渲染像素预检；解析及渲染/OCR 采用限时短生命周期子进程。
- 支持稳定单栏、双栏、三栏阅读顺序和保守表格降级；清晰网格扫描表格可输出 Tab 行列。报告增加逐页来源、模型、置信信息、警告和潜在损失。
- 任一必要页处理失败时整份 PDF 失败，不交付部分 TXT；批次中的其他文件继续。

## 验证结果

- OpenSpec 变更 `add-pdf-to-txt-v2` 的 19 项任务完成，PDF 增量规格已同步至主规格并归档。
- 本机全量 pytest：123 项通过；V1 六路径回归、PDF 安全和失败路径均在测试范围内。
- 九份固定真实 PDF 自动门槛：9/9 通过。网页已验收至少五文件混合批次与 ZIP 交付。
- 固定哈希五页旧印刷体：人工参考在评分前冻结，5012 个参考字符、344 编辑距离，默认 `standard` 配置正确率 93.1365%；逐页最低为 91.1616%。详见[正式评分记录](../validation/2026-09-24-old-print-formal-score.md)。
- 项目自制的 150 PPI 中文扫描表格 PDF、TXT 和 JSON 报告可公开演示；第三方 PDF 与人工参考全文不进入仓库。

## 已知限制

- 90% 门槛仅在上述固定五页旧书样例上验证，不代表所有旧书或扫描件的准确率。
- 90° 旋转密集表的行列关系不可读；联邦公报跨栏密集表与图片文字恢复不完整；复杂表单、公式和局部中英混排仍可能错序。三份布局样例保留 `known-issue`。
- OCR 模型按项目说明显式准备；转换过程不下载模型。PDF 子进程有超时和输入限额，但没有绝对内存上限，也不是完整系统沙箱。
- 本版不制作 macOS、Windows 或 Android 安装包，也不增加 PDF → DOCX 或其他输入格式。
