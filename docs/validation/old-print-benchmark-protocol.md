# 固定五页旧印刷体逐页验收协议

此协议在正式字符评分前确定，适用于 `wikimedia-chinese-scan`，PDF SHA-256 为 `42a672355b951c91324ce4f5ae7b1ddbced6c096fe5adca69c9f828c91a7a04f`，共 5 个 PDF 页面（每页为扫描的双页摊开图）。原 PDF 与逐字参考文本仅留在本机的 Git 忽略目录。

## 转写与排除规则

1. 按 PDF 第 1–5 页分别保存 `page-1.txt` 至 `page-5.txt`。每页先读右半页，再读左半页；每半页按从右到左的竖排列序转写。跨页句子分别留在各自的 PDF 页面，不为流畅而移到相邻页。
2. 包含所有可辨认的文章正文、标题、署名、分项编号、引文、英文词、数字和标点。只为排版方便插入的空白及换行可自由使用；Unicode NFKC 和去空白由评分器统一处理。不得把繁体字改成简体字，也不得为贴合 OCR 输出而更改原文字词。
3. 事前排除每页重复的竖排页边栏题“附錄／公禱書四百年之紀念”以及扫描原件印刷页码（第 1–4 PDF 页可见 73–79，第 5 页可见 80）。第 1 页右侧文章的独有标题、左侧新文章标题与署名，以及第 5 页文章末尾出处，**不**属于排除区域。其他独有边栏文字若可辨认，应包含；不可辨认处在本地逐页备注中注明，不事后随评分结果调整。
4. 不把污点、装订黑边、透页影像或不存在于原页的 OCR 杂字当作参考正文。参考文本若难以辨认，应在本地备注中标注原页坐标和原因；不能默默用 OCR 猜字。正式评分前必须解决或事先固定这类位置的处理方式。
5. 初始 OCR 输出仅可作为**待校对草稿**，不等于人工标准答案。第二位复核者须对照五页原图逐行检查并确认：排除范围未改动、五个逐页文件完整、阅读顺序可读。签核后计算每页文件哈希并冻结；其后任何修订都需撤销旧成绩并重新签核。

## 计分与发布边界

使用代码中的 `score_pages`：参考与最终交付 TXT 的逐页文本分别做 NFKC 和去 Unicode 空白，保留标点、英文、数字，逐页求 Levenshtein 距离，再用总编辑距离除以总参考字数。发布门槛为聚合正确率至少 90%，同时公开五个逐页分数和主要错漏类别；不得用 OCR 自报置信度或用户此前约 4% 的总体估计代替。若某页严重失真，独立复核不得仅凭总体过线签核。

九份真实样例的布局已知问题另行记录；旋转密集表、跨栏密集表、复杂表单/公式、图片内文字的结构恢复不是这五页字符门槛的组成部分，但必须在发布说明中保留限制。
