# 竖排 OCR 阅读顺序验证

## 目标

在不更换 PP-OCRv5 模型、不增加网络依赖的前提下，改进繁体中文竖排双页扫描 PDF 转 TXT 的阅读顺序。

## 根因与方案

PP-OCRv5 已将大部分竖排列识别为自上而下的完整字符串，原问题是后处理统一使用横排的“上到下、左到右”坐标排序。新规则只在以下特征同时成立时启用：

- 至少四个中文竖向文字块。
- 竖向块中文字符至少二十个，且占有几何信息的中文字符过半。
- 竖向块的中位高宽比不小于 3。

命中后，先按水平中心将被 OCR 切开的同列文字聚合，再将列按从右到左排列，同列文字块按从上到下排列。特征不足时继续使用原横排规则。

## 验证结果

- 新增竖排双页、同列分块和横排误判防护的单元测试。
- `wikimedia-chinese-scan` 全部 5 页命中竖排检测并完成重排。
- 实际输出按右页到左页、同页右列到左列排列，不再出现横向逐行交插。
- 输出 5048 个字符，其中中日韩统一表意文字 4258 个、拉丁字母 177 个。
- 五页 OCR 平均置信度仍约为 0.84，没有因重排而改变识别置信度。

## 剩余限制

- 列序已恢复，但 PP-OCRv5 对旧式繁体铅印仍有明显错字和漏字。
- 后续已加入跨页重复边栏标题清理与竖排页码候选记录，详见 [第三批 OCR 验收](2026-09-23-pdf-ocr-third-batch-validation.md)。独有的页边文字仍需人工复核。
- 异形竖排、书法体、大量横竖混排和单列过短的页面可能不触发竖排检测。
