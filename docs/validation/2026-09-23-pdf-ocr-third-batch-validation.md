# PDF OCR 第三批验证：竖排页边、高质量识别与现代扫描

## 范围与样例

- 旧式竖排样例：`wikimedia-chinese-scan`，1949 年繁体中文双页扫描，5 页。原始 PDF 只在本地保存，来源见 `quality/pdf_corpus/manifest.json`。
- 现代横排样例：云南大学公开的[云南省财政厅公文扫描件](https://www.zczx.ynu.edu.cn/__local/F/C6/9B/E99C9D4CB9A869D4E299B7A987D_1A09B0EA_2B15E5.pdf)，2024 年由扫描应用生成的四页 A4 PDF。四页都只有图像、没有可提取文字层。二进制文件仅本地保存，固定大小 2,823,653 字节，SHA-256 为 `c47a2e5b9c329e6ec39ab99a77aabb0d9829ae72746df2e8abececdeed24f100`。

## 竖排页眉页码

竖排 OCR 的第一轮重排已恢复正文列序，但每张扫描图的最外侧列可能含重复的书名页边标题和原书页码。本轮先在 OCR 几何结果中标记左右最外侧的短列：下部短数字或近形汉字作为页码候选，移出 TXT 正文，并在报告的 `printed_page_numbers` 中保留原始识别值。重复的页边标题只在至少三页、超过半数相关页出现相似文本时移除；独有的页边标题继续保留。

这不是对所有边栏的语义理解。旧书第一页右边的独有章节标题仍在正文开头；个别页码被识别成非数字汉字，报告中的值只能作为候选。

## 旧印刷体识别

同页比较了基础 200 DPI、300 DPI、自动对比度和锐化。图像增强有局部收益，也会新增错字，未设为默认。随后实测了 PaddleOCR 官方的 `PP-OCRv5_server_rec`：官方[模型说明](https://paddlepaddle.github.io/PaddleOCR/main/version3.x/module_usage/text_recognition.html)列出它在繁体中文及复杂文本上的基准优势；本机用现有检测模型和页面方向模型，仅替换识别模型做验证。

人工对照原页挑出的八个短语，在旧版 mobile 输出中命中 2 个，在 server 输出中命中 8 个，例如“聖餐禮拜時加讀舊約的經選”“總議會再作報告”“心靈與誠實之崇拜”。这是小范围抽查，不能当作全文字符错误率。server 输出仍有明显误字和漏字，尤其旧字体、印刷磨损和少量英文混排。OCR 平均置信度不一定随可读性同步上升。

`scripts/prepare_paddleocr_models.py --high-accuracy` 可由用户显式准备约 81 MB 的额外识别模型；本地目录存在该模型时转换优先使用它，逐页报告记录 `ocr_recognition_model=server`。基础三个模型仍可独立工作，转换过程不下载模型。

本机五页复验中，输出 5,040 字符，中文统一表意文字 4,208 个，五页 OCR 平均置信度 0.8389。五页都移除了重复边栏标题；页码候选按页记录为 `世/七三`、`七四/七五`、`七六/七七`、`大/七九`、空。`世` 和 `大` 是页码误识别，报告保留原值，不自动猜成正确数字。

## 现代横排扫描结果

四页均被分类为扫描页并触发离线 OCR。正文标题、段落和编号整体可读；第一页背景透字被识别出少量无意义字符，第三页印章会影响相邻字，第四页长网址按印刷行断开，不能直接复制为链接。它为现代简体中文扫描提供了与旧式繁体竖排不同的真实验收样例。

本机四页复验输出 1,679 字符，其中中文统一表意文字 1,316 个、拉丁字母 66 个，四页 OCR 平均置信度 0.9524。该值说明模型对识别块有较高置信度，不表示网址和印章区域逐字正确。

自动验收约束页数、OCR 页数、中文与拉丁文字数量、最小文字量和平均置信度；人工验收仍需对照四页原图。后续应补充同一内容的 150/300 DPI、倾斜和模糊对照，以及带扫描表格的样例。

本次完整质量集的 9 份样例全部通过自动门槛；自动通过不覆盖旧式印刷错字、三栏错序、旋转表格和中英跨页交错等人工已知问题。全量 `pytest` 为 93 项通过。
