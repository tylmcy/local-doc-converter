# 固定五页旧印刷体正式字符评分（2026-09-24）

## 结论

固定哈希五页旧印刷体样例在默认生产配置下取得 **93.1365%** 聚合字符正确率，达到 OpenSpec
规定的 **90%** 发布门槛。该结论只适用于这份固定样例，不代表任意旧书或扫描件均能达到相同准确率。

## 冻结与计分口径

- 源 PDF SHA-256：`42a672355b951c91324ce4f5ae7b1ddbced6c096fe5adca69c9f828c91a7a04f`，共 5 个 PDF 页面。
- 人工参考按 [事前协议](old-print-benchmark-protocol.md) 逐页建立：每页先右半叶后左半叶、每半叶从右到左；
  排除事前声明的重复边栏题和印刷页码，保留独有标题、署名、正文及文末出处。
- 项目所有者逐页对照原图确认参考文本、疑难字和原刊疑似排印问题；五页参考在正式评分前冻结，
  NFKC 去空白后字数为 824、1257、1265、1188、478，合计 5012。
- 评分使用 `pdf-character-accuracy-v1`：逐页 NFKC、去 Unicode 空白、保留标点及繁简差异，
  分别计算 Levenshtein 距离后按参考字符数加权。参考全文、机器全文、逐页哈希和差异样例只保存在
  Git 忽略目录，不随仓库发布。

配置为默认 `standard`（200 DPI、无旧印刷体额外去噪），识别使用本地

五页均高于 90%，最低的第 4 页没有严重失真被聚合结果掩盖。主要差异仍是旧字形近替换、繁简差异、
漏字和标点差异；因此文档仍应人工校对，不能宣传为无错 OCR。

此前外部人工估计的宽口径错误率为 6.25%–7.5%；本次严格公式得到 6.8635% 错误率，两者相符。
实验性 `old_print` 配置未显示稳定收益，发布默认仍保持 `standard`，不从多个参数中挑最高分替代生产配置。
